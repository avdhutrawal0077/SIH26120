## Brand & Style

This design system serves upstream, midstream, and subsea petroleum engineers, operations managers, and automation specialists monitoring continuous industrial telemetry. The visual language conveys high reliability, mission-critical precision, and physical equipment grounding without visual noise.

The style combines high-density data instrumentation with modern digital twin telemetry interfaces. It draws from technical precision instruments and industrial control rooms:
- **Structural Integrity:** Heavy reliance on clear boundaries, tabular numerical data alignment, and low-radius modular surfaces.
- **Dual-Zone Architecture:** A high-contrast deep spruce evergreen navigation anchor paired with a pale ivory low-fatigue daylight operating canvas.
- **Instrument Precision:** Purpose-built status indicators, strict metric hierarchies, and zero decorative ornamentation.

## Colors

The palette establishes an ergonomic, high-legibility telemetry environment configured for long-shift operations.

### Canvas & Structural Surfaces
- **Sidebar Surface:** `#001F12` — Deep evergreen backdrop for system-level hierarchy, navigation, and structural anchoring.
- **Main Canvas:** `#FFFFE4` — Pale industrial ivory canvas reducing retina fatigue during daylight field control operations.
- **Card Surfaces:** `#FFFFFF` (Primary elevated containers) and `#EAF7EF` (Nested telemetry panels and equipment sub-bays).
- **Structural Boundaries:** `#C9DCCF` — Muted sage border for division and technical framing.

### Primary & Accent Spectrum
- **Primary Spruce:** `#003B25` — Anchoring interactive brand element, primary buttons, and critical active tabs.
- **Secondary Forest:** `#006B45` — Secondary action triggers, progress indicators, and active node pathways.
- **Telemetry Accent:** `#00A86B` — Real-time telemetry indicators, active breadcrumb notches, and selected equipment outlines.
- **Tonal Tints:** `#D9F2E6` (Active highlights, selection fills) and `#EAF7EF` (Container backdrops).

### Typography Tones
- **Primary Text:** `#10251B` — Deep forest black for data values, telemetry readouts, and section headers.
- **Secondary Text:** `#52665C` — Muted sage-slate for engineering units (e.g., PSI, BPD), metadata, and grid scales.
- **Sidebar Primary Text:** `#FFFFE4` — Pale ivory for primary navigation links.
- **Sidebar Secondary Text:** `#A3D9BE` — Pale mint for subsystem status and navigation metadata.

### Operational State System
- **Nominal / Success:** `#22C55E` — Flow rates and pressure within nominal operating envelope.
- **Advisory / Warning:** `#F59E0B` — Deviations, throttling thresholds, and upcoming maintenance cycles.
- **Critical / Danger:** `#EF4444` — Emergency shutoffs (ESD), blowout preventer (BOP) alarms, over-pressure events.
- **Telemetry / Info:** `#2563EB` — Remote sensor handshakes, network sync, calibration sweeps.

## Typography

The typography system relies exclusively on Inter, configured for dense information extraction.

- **Tabular Numerics Rule:** All numbers, data outputs, timestamps, and coordinates must strictly use tabular figures (`font-variant-numeric: tabular-nums; font-feature-settings: "tnum" 1;`). This prevents jitter in dynamically updating telemetry streams.
- **Unit Hierarchy:** Measurements (e.g., `PSI`, `BPD`, `m³/h`, `°C`) must be scaled to `unit-label`, rendered in uppercase with `#52665C`, and tethered directly to values without dominating visual weight.
- **Headings & Hierarchy:** Deep forest black (`#10251B`) is reserved for critical titles and values. Sub-labels and metadata systematically drop to `#52665C`.

## Layout & Spacing

The layout uses a split-shell architecture optimized for telemetry displays: a permanent 260px fixed sidebar paired with a fluid, multi-column dashboard canvas.

### Layout Mechanics
- **Sidebar Integration:** A 260px fixed-width navigation bar docked permanently on desktop, collapsing to an icon rail (64px) on tablet viewports, and hidden off-canvas on mobile devices.
- **Dashboard Canvas:** Fluid 12-column grid utilizing a baseline 4px increment scale for dense telemetry tables and digital twin views.
- **Gutters & Margins:** Default desktop spacing uses `1rem` (16px) gutters to maintain compact grouping of sensor clusters. Large display viewports (1920px+) scale to `gutter-lg` (`1.5rem`).

### Form Factor Behavior
- **Desktop (1280px+):** Full 12-column grid. Complex drill-string telemetry and subsea P&ID graphics render alongside real-time time-series charts.
- **Tablet (768px - 1279px):** 6-column grid. Sidebar condenses to a 64px tool dock. Secondary telemetry parameters collapse into expandable drawers.
- **Mobile (< 768px):** 4-column single-stack stream. Margins drop to `margin-sm` (`1rem`). Critical alerts and shutdown controls remain pinned at top.

## Elevation & Depth

This system avoids blurred ambient drop-shadows to ensure visual crispness under variable field lighting. Depth is constructed through flat tonal layering, high-contrast borders, and technical inset surfaces.

### Depth Hierarchy
1. **Level 0 (Base Canvas):** Pale ivory `#FFFFE4`. Provides a low-reflectivity surface for the entire viewport.
2. **Level 1 (Card Panels & Bounded Modules):** `#FFFFFF` surfaces bounded by a crisp 1px solid `#C9DCCF` border. No drop shadows.
3. **Level 2 (Nested Sub-bays & Telemetry Cell Containers):** `#EAF7EF` container surfaces inset within Level 1 cards, bounded by 1px `#C9DCCF`. Used for data clusters, telemetry readouts, and wellbore sensor arrays.
4. **Level 3 (Interactive Floating Panels & Tooltips):** `#FFFFFF` surface with a crisp 1px solid `#003B25` outline and a flat 2px offset shadow (`2px 2px 0px rgba(0, 59, 37, 0.15)`).
5. **Level 4 (Modals & Emergency Override Overlays):** `#FFFFFF` cards framed by a 2px `#003B25` perimeter over a 40% `#001F12` tinted backdrop.

## Shapes

The design uses tight, geometric corner radii (`roundedness: 1`) to preserve perimeter space and emulate physical telemetry hardware.

- **Standard Elements (Buttons, Inputs, Metric Badges):** `0.25rem` (4px). Provides edge definition while maintaining compact density.
- **Structural Cards & Panels:** `0.25rem` (4px). Keeps modular telemetry cards cleanly aligned along common grid vectors without soft corner gaps.
- **Modals & Flyouts:** `0.5rem` (8px). Subtle distinction for floating system interactions.
- **Pills / Status Dots:** Strict circular forms (50% radius) reserved only for active ping lights, valve state markers, and connectivity indicators.

## Components

### Buttons
- **Primary Button:** Background `#003B25`, text `#FFFFE4`, 1px solid `#003B25` border, `roundedness: 1` (4px). Hover transitions to `#006B45`. Active/Pressed triggers a 1px inset boundary.
- **Secondary Button:** Background `#FFFFFF`, text `#003B25`, border 1px solid `#C9DCCF`. Hover transitions to background `#EAF7EF` and border `#006B45`.
- **Destructive / Emergency Action Button:** Background `#EF4444`, text `#FFFFFF`, border 1px solid `#EF4444`. Hover state `#DC2626`.
- **Button Sizing:** Compact 32px height for high-density toolbars; 40px standard for form submissions. All typography set to `label-md` with tabular numerals.

### Cards & Telemetry Pods
- **Primary Data Card:** Background `#FFFFFF`, 1px solid `#C9DCCF` border, 4px border-radius, padding `space-lg` (16px).
- **Nested Well-Bay Box:** Background `#EAF7EF`, border 1px solid `#C9DCCF`, inner padding `space-md` (12px).
- **Telemetry Metric Pod:** Houses an upper subtext label (`label-sm` in `#52665C`), an oversized value (`metric-value-lg` in `#10251B` with tabular numbers), and an attached inline unit label (`unit-label`).

### Navigation Rail (Sidebar)
- **Container:** Background `#001F12`, border-right 1px solid `#003B25`.
- **Navigation Item:** Base state text `#A3D9BE`, hover background `#003B25` with text `#FFFFE4`.
- **Active Navigation Item:** Background `#003B25`, text `#FFFFE4`, with a prominent 3px left border indicator in Accent Green `#00A86B`.

### Form Controls (Inputs, Checkboxes, Radios)
- **Text & Numeric Inputs:** Background `#FFFFFF`, border 1px solid `#C9DCCF`, text `#10251B`, 4px radius. Focus state: border 1.5px solid `#00A86B` with a subtle `#D9F2E6` focus ring (2px).
- **Checkboxes & Radios:** 16px square/circle with 1px solid `#52665C` border on `#FFFFFF`. Checked state: background `#003B25` with `#00A86B` inner check indicator.

### Status Chips & Badges
- **Nominal Badge:** Background `#EAF7EF`, border 1px solid `#22C55E`, text `#10251B`, with a 6px solid `#22C55E` leading indicator dot.
- **Warning Badge:** Background `#FFFBEB`, border 1px solid `#F59E0B`, text `#B45309`, with a 6px solid `#F59E0B` dot.
- **Danger / Alarm Badge:** Background `#FEF2F2`, border 1px solid `#EF4444`, text `#B91C1C`, with a pulsing 6px `#EF4444` dot.

### Specialized Telemetry Components
- **Wellbore Depth Log / Strip Chart:** Background `#FFFFFF`, gridlines 1px solid `#EAF7EF`, axis values set in `body-sm` `#52665C`, data vectors plotted with `#00A86B` and `#006B45`.
- **Valve & Choke Actuator Status Display:** Compact segmented control displaying percentage open. Active slice rendered in `#006B45` over an `#EAF7EF` track with numeric percentage in `metric-value-md`.
- **Data Table:** Alternating rows using `#FFFFFF` and `#F8FDF9`. Header row styled in `#EAF7EF` with 1px solid bottom border `#C9DCCF` and uppercase `label-sm` headers.
